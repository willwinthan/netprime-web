# คู่มือทำบทเรียน Self-learning (Lesson Kit v1)

บทเรียน Self-learning คือไฟล์ `.html` ไฟล์เดียวที่อัปโหลดในหลังบ้าน เมนู "บทเรียน Self-learning" (ต้องมีสิทธิ์ `site.self_learning`) บทเรียนที่เผยแพร่แล้วจะแสดงที่ `/self-learning` บนเว็บ และเปิดในกรอบ (iframe) ใต้หัวเว็บ NetPrime

Lesson Kit คือสคริปต์สั้น ๆ ในไฟล์บทเรียนที่ทำให้บทเรียนคุยกับเว็บได้ ได้ 4 อย่าง:

1. **สีและฟอนต์ตามธีมของเว็บ** เมื่อแอดมินเปลี่ยนธีมในหน้า "เว็บไซต์ → ธีมและแบรนด์" ทุกบทเรียนเปลี่ยนตามโดยไม่ต้องอัปโหลดใหม่
2. **กรอบสูงพอดีเนื้อหา** ไม่มีแถบเลื่อนซ้อนกัน
3. **จำตำแหน่งใน URL** แชร์ลิงก์แล้วเปิดตรงขั้นที่กำลังดู
4. **เก็บความคืบหน้าของผู้เรียนที่ login** ไว้ในระบบ เรียนต่อจากเครื่องอื่นได้ และแสดงบนการ์ดบทเรียน ส่วนคนที่ไม่ได้ login ยังเก็บในเบราว์เซอร์ตามเดิม

## ใช้บทเรียนในคอร์ส

ผู้สอนใส่บทเรียน Self-learning ในคอร์สได้: หน้าสร้างคอร์ส → เพิ่มบทเรียน → ประเภท **Self-learning** แล้วเลือกจากคลังบทเรียนที่เจ้าหน้าที่อัปโหลดไว้ ผู้สอนไม่อัปโหลดไฟล์ HTML เอง ถ้าต้องการบทเรียนใหม่ให้ส่งไฟล์ให้เจ้าหน้าที่

- **การแสดงผล** (ตั้งในหลังบ้าน): "แสดงบนหน้าเว็บ" = อยู่ที่ `/self-learning` ให้ทุกคนเรียนฟรี และใช้ในคอร์สได้ด้วย, "ใช้ในคอร์สเท่านั้น" = ไม่แสดงบนหน้าเว็บ เปิดได้เฉพาะผู้เรียนที่ลงทะเบียนคอร์สที่ใช้บทเรียนนี้ (ไฟล์เปิดผ่านลิงก์ลงนามที่ได้จากหน้าเรียนของคอร์สเท่านั้น)
- **นับว่าเรียนจบ**: ทั้งบทเรียน เมื่อบทเรียนเรียก `saveProgress({ completed: true })` ระบบติ๊กบทเรียนนั้นในทุกคอร์สของผู้เรียนที่ใช้บทเรียนนี้ (ยกเว้นบทที่ยังล็อกอยู่) จึงนับในความคืบหน้าของคอร์สและใบประกาศ บทเรียนที่ไม่ใช้ Lesson Kit ให้ผู้เรียนกด "ทำเครื่องหมายว่าเรียนแล้ว"
- ลบบทเรียนที่มีคอร์สใช้อยู่ต้องยืนยันด้วยรหัสทางอีเมล บทเรียนในคอร์สจะไม่มีเนื้อหาจนกว่าผู้สอนจะเลือกบทใหม่

## เริ่มต้น

1. ดาวน์โหลดไฟล์ต้นแบบจากปุ่ม "ไฟล์ต้นแบบ" ในหลังบ้าน (หรือ `frontend-admin/public/lesson-kit/netprime-lesson-template.html` ใน repo)
2. แก้ `STEPS` และ `QUIZ` หรือเขียนหน้าใหม่ทั้งหมดก็ได้ แต่**ต้องเก็บบล็อก "NetPrime Lesson Kit v1" ไว้ไม่แก้**
3. เปลี่ยนค่า `KEY` ให้ไม่ซ้ำกับบทเรียนอื่น (ชื่อที่ใช้เก็บความคืบหน้าในเบราว์เซอร์)
4. เปิดไฟล์ในเบราว์เซอร์ตรง ๆ เพื่อลอง จะเห็นสี NetPrime ค่าเริ่มต้น
5. อัปโหลดในหลังบ้าน ดูผลตรวจไฟล์ กด "ดูตัวอย่าง" แล้วจึงกด "เผยแพร่"

## กติกาของไฟล์

- ไฟล์เดียว ขนาดไม่เกิน 15 MB เข้ารหัส UTF-8 ขึ้นต้นด้วย `<!doctype html>`
- ใส่ CSS, JavaScript, รูป (`data:` หรือ SVG) ไว้ในไฟล์ หรือโหลดจากเว็บภายนอกที่เชื่อถือได้ ผลตรวจไฟล์จะบอกว่าไฟล์อ้างถึงเว็บใดบ้าง
- ใช้สีผ่านตัวแปรของเว็บแทนการใส่สีเอง:

| ตัวแปร | ใช้กับ |
| --- | --- |
| `--np-primary` | ปุ่มหลัก ลิงก์ ไฮไลต์ (ผ่าน contrast 4.5:1 กับตัวอักษรสีขาว) |
| `--np-primary-dark` | ปุ่มตอน hover |
| `--np-primary-tint` | พื้นหลังอ่อนของสิ่งที่เลือกอยู่ |
| `--np-accent` | ของตกแต่ง ไม่ใช้กับตัวอักษร |
| `--np-secondary` | สีตัวอักษรหลัก (น้ำเงินเข้ม) |
| `--np-radius` | ความโค้งของมุม |
| `--np-font` | ชุดฟอนต์ของเว็บ |

  ประกาศค่าเริ่มต้นของตัวแปรเหล่านี้ใน `:root` ไว้เสมอ (ไฟล์ต้นแบบมีให้แล้ว) เพื่อให้เปิดไฟล์ตรง ๆ ได้
- ห้ามพยายามเปลี่ยนหน้าเว็บหลัก (`window.top.location`) ห้ามขอรหัสผ่านหรือข้อมูลส่วนตัวในบทเรียน และห้ามใช้ `<form>` ส่งข้อมูลออกไป (ระบบบล็อกไว้)

## Lesson Kit API

บล็อก Lesson Kit สร้าง `window.NetPrimeLesson`:

| ฟังก์ชัน | ทำอะไร |
| --- | --- |
| `embedded` | `true` เมื่อเปิดอยู่ในเว็บ, `false` เมื่อเปิดไฟล์ตรง ๆ |
| `shareUrl` | ลิงก์หน้าบทเรียนบนเว็บ ใช้กับปุ่มแชร์ (เป็น `null` จนกว่าเว็บจะส่งมา) |
| `onTheme(fn)` | เรียก `fn(theme)` เมื่อเว็บส่งธีม Kit ตั้งตัวแปร `--np-*` ให้เองแล้ว ใช้เมื่อต้องวาดสีเองใน canvas/SVG |
| `onRestore(fn)` | เรียก `fn(state, info)` เมื่อเว็บส่งความคืบหน้าที่บันทึกไว้ของผู้เรียนที่ login (`info.signedIn` บอกว่า login หรือไม่) **อาจถูกเรียกซ้ำ ต้องรวมค่าแบบเรียกกี่ครั้งก็ได้ผลเท่าเดิม** เช่นเลือกค่าที่ไปไกลกว่า |
| `saveProgress({ percent, completed, state })` | บันทึกความคืบหน้า `percent` 0–100, `completed` เป็น `true` เมื่อเรียนครบ (บันทึกครั้งแรกแล้วไม่ถูกลบ), `state` เป็น JSON อะไรก็ได้ไม่เกิน 64 KB Kit รวมการเรียกถี่ ๆ เป็นครั้งเดียวทุก 0.8 วินาที |
| `setLocation(hash)` | ให้ URL ของเว็บจำตำแหน่ง ใช้ได้เฉพาะ a-z, 0-9, ขีดกลาง และ `/ตัวเลข` เช่น `step-2` หรือ `dhcp/3` |
| `resize()` | ส่งความสูงของเนื้อหา Kit เรียกเองเมื่อขนาดเปลี่ยน |

ตอนเปิดบนเว็บ ลิงก์ที่มี `#ตำแหน่ง` จะถูกส่งต่อเข้าไปในไฟล์ บทเรียนอ่าน `location.hash` ตอนเริ่มเพื่อเปิดตรงขั้นนั้น

## ข้อความระหว่างเว็บกับบทเรียน (สำหรับนักพัฒนา)

ใช้ `postMessage` ชนิดขึ้นต้นด้วย `netprime-lesson:` (บทเรียน Basic Network ใช้ `protocol-explorer:` ซึ่งเว็บยังรองรับ):

| ทิศทาง | ชนิด | ข้อมูล |
| --- | --- | --- |
| บทเรียน → เว็บ | `ready` | บทเรียนพร้อมรับธีมและความคืบหน้า |
| บทเรียน → เว็บ | `height` | `height` (px) |
| บทเรียน → เว็บ | `location` | `hash` |
| บทเรียน → เว็บ | `progress` | `percent`, `completed`, `state` (เว็บบันทึกที่ `PUT /api/me/self-learning/:slug` เมื่อ login) |
| เว็บ → บทเรียน | `theme` | `theme.vars` (ตัวแปร `--np-*`), `theme.font`, `theme.fontHref`, `theme.custom` |
| เว็บ → บทเรียน | `parent` | `url` ลิงก์หน้าบทเรียนบนเว็บ |
| เว็บ → บทเรียน | `restore` | `signedIn`, `state`, `percent` (ส่งครั้งเดียวต่อการโหลดกรอบ) |

เว็บรับข้อความเฉพาะจากกรอบบทเรียนและจาก origin ที่เสิร์ฟไฟล์ ส่วนไฟล์บทเรียนรับเฉพาะข้อความจากหน้าแม่ (`e.source === window.parent`)

## ความปลอดภัย

ไฟล์บทเรียนรันสคริปต์ได้ จึงเสิร์ฟจากโดเมนแยก (`SELF_LEARNING_ORIGIN` หรือโดเมน API) ไม่ใช่โดเมนของเว็บ บทเรียนจึงอ่าน token ที่ login อยู่ไม่ได้ ไฟล์ถูกฝังได้เฉพาะในเว็บที่ตั้งไว้ใน `FRONTEND_ORIGINS` และกรอบใส่ `sandbox` ทำให้บทเรียนพาหน้าเว็บไปที่อื่นไม่ได้ ข้อมูลที่บทเรียนส่งมาในความคืบหน้าถูกเก็บแยกตามบัญชีผู้เรียน และอยู่ในไฟล์ส่งออกข้อมูลส่วนบุคคล (PDPA)

ถึงอย่างนั้น ผู้ที่อัปโหลดได้คือผู้ที่เปลี่ยนสิ่งที่ผู้เข้าชมเห็นได้ทั้งหมดในกรอบนั้น ให้สิทธิ์ `site.self_learning` เฉพาะเจ้าหน้าที่ที่ไว้ใจ และตรวจไฟล์จากคนนอกก่อนอัปโหลด
